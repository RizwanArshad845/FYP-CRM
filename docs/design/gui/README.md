# AICRE GUI mockups

These files are the source of the Graphical User Interface figures in the AICRE FYP report (Section 4.8). The app must look like them. See Section 9 of `AICRE_FYP_PLAN.md`.

| Report figure | Mockup | Render |
|---|---|---|
| Figure 4.1 Login Page | `login.html` | `gui_login.png` |
| Figure 4.2 Onboarding Wizard: Portal Selection | `onboarding.html` | `gui_onboarding.png` |
| Figure 4.3 AI Assistant Panel (Phase 2) | `ai_panel.html` | `gui_ai_panel.png` |
| Figure 4.4 Pipeline Kanban Board | `kanban.html` | `gui_kanban.png` |
| Figure 4.5 Deactivation Requests Approval Screen | `deactivation.html` | `gui_deactivation.png` |
| Figure 4.6 Permissions Settings Screen | `permissions.html` | `gui_permissions.png` |

`base.css` holds the shared tokens (colors, sidebar, top bar, cards, buttons, tables, tags). The mockups are drawn at 1280 by 720 pixels. Sample names and data in them are illustrative only.
